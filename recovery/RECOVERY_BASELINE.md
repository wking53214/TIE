# TIE Forensic Recovery Baseline

This build uses five user-supplied forensic summaries as its evidence corpus.

No summary is treated as authoritative solely because it appears later in the conversation. Common architecture was reconciled; historical differences and uncertainty are retained.

### Status taxonomy used

- RECOVERED
- PARTIALLY_RECOVERED
- RECONSTRUCTED
- IMPLEMENTED_FROM_RECOVERED_SPEC
- PROPOSED
- SUPERSEDED
- CONFLICTED
- UNKNOWN

The implementation is not represented as historical source recovery.
