# TIE Data Model

## Canonical

- `SourceRecord`
- `Coverage`
- `EvidenceRecord`
- `Artifact`
- `IdentityReference`
- `Relationship`

## Derived

- `Reconstruction`
- `ValidationResult`
- `TypedHandoff`
- `knowledge_views`
- `routing_signal`

## Epistemic states

- `EXPLICIT`
- `INFERRED`
- `UNKNOWN`
- `CONFLICTED`

The implementation does not add canonical first-class structures for events, state, decisions, requirements, constraints, assumptions, claims, questions, risks, conflicts, timelines, or workflow state.
